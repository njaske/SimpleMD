The real app. Not a mockup.

Every frame is SimpleMD 1.1 running on Windows, opening the kind of Markdown an AI assistant hands you. Flip the site theme and the app follows.

An AI answer, rendered the way it was meant to look: typeset equations, highlighted code and a live outline.

Pick a step, or let it play.

Engineered for documents that matter.

Everything you need to read and fix what an AI wrote, and nothing that gets in the way.

KaTeX Math Rendering

Inline $…$ and display $$…$$ math, typeset by KaTeX the moment the file opens. Fractions, integrals, matrices, all of it.

Inline Mermaid Diagrams

Flowcharts, sequence diagrams and class models drawn straight from ```mermaid blocks, as crisp vectors that follow your theme.

CodeMirror 6 Source Editor

The editor behind modern code tools: line numbers, find and replace, bracket matching and Markdown highlighting. Fix the AI's typo, press Ctrl+S, done.

Live Outline & Search

A heading outline that jumps you through long documents, and instant search across every file in the folder you opened.

One-Click PDF Export

Press Ctrl+P for a clean A4 PDF with the equations, diagrams and code exactly as you see them.

Folders & Reading Customization

Open a whole folder at once, no import step. Pick Sans, Serif or Mono, set the reading width and accent, and switch light or dark.

Safe with files from anyone.

A Markdown file from the internet should never be able to touch your computer. SimpleMD treats every document as untrusted.

DOMPurify Sanitization

Every embedded HTML tag or raw SVG is stripped of onerror, onload, and executable script payloads before touching the DOM.

Sandboxed Renderer & CSP

The page that shows your document is sandboxed with no Node access, and a strict Content-Security-Policy allows only the app's own scripts. It can only read the files and folders you opened.

Atomic File Writes

Saves go to a hidden temporary file in the same folder, then are renamed over the original, so a crash mid-write cannot leave a truncated file.

The SimpleMD Philosophy

Open a file. Read. Write. Nothing else.

No accounts. No telemetry. No cloud. No AI rewriting your notes. SimpleMD does one thing, showing your Markdown beautifully, and gets out of the way.

About the Windows SmartScreen warning

Why this happens: SimpleMD is a free, open-source project and is not code-signed, because signing certificates cost money the project does not spend. Windows SmartScreen warns about any unsigned app that has not yet built up download reputation.

Windows protected your PC

Verify the download yourself:

Every release lists SHA-256 checksums in SHA256SUMS.txt. Compare with certutil -hashfile SimpleMD-Setup.exe SHA256.

The scan reports above match these exact checksums. You can also read every line of the source on GitHub and build it yourself.
