# Keyboard shortcuts

A short, honest list. Nothing you need to memorize: press `Ctrl` + `K` (`Cmd` + `K` on a Mac) to find any command by name, and `Ctrl` + `/` to see this list inside the app.

On macOS, read `Ctrl` as `Cmd` in every row below.

## Documents

| Action | Shortcut |
| --- | --- |
| New document | `Ctrl` + `N` |
| Open file | `Ctrl` + `O` |
| Open folder | `Ctrl` + `Shift` + `O` |
| Paste from AI as a new document | `Ctrl` + `Shift` + `V` |
| Save | `Ctrl` + `S` |
| Save as | `Ctrl` + `Shift` + `S` |
| Save all | `Ctrl` + `Alt` + `S` |
| Rename | `F2` |
| Export PDF | `Ctrl` + `Shift` + `E` |

## Tabs and navigation

| Action | Shortcut |
| --- | --- |
| Close tab | `Ctrl` + `W` |
| Reopen closed tab | `Ctrl` + `Shift` + `T` |
| Next tab | `Ctrl` + `Tab` or `Ctrl` + `Alt` + `→` |
| Previous tab | `Ctrl` + `Shift` + `Tab` or `Ctrl` + `Alt` + `←` |
| Quick open (files) | `Ctrl` + `P` |
| Command palette | `Ctrl` + `K` or `Ctrl` + `Shift` + `P` |
| Find in document | `Ctrl` + `F` |
| Search all files | `Ctrl` + `Shift` + `F` |

## Reading

| Action | Shortcut |
| --- | --- |
| Read / Split / Edit | `Ctrl` + `1` / `2` / `3` |
| Switch between Read and Edit | `Ctrl` + `E` |
| Toggle sidebar | `Ctrl` + `B` |
| Toggle outline | `Ctrl` + `\` |
| Focus mode | `Ctrl` + `.` |
| Toggle light and dark | `Ctrl` + `Shift` + `D` |
| Bigger / smaller / reset text | `Ctrl` + `=` / `-` / `0` |
| Next change / dismiss changes | `Alt` + `N` / `Esc` in the change bar |
| Settings | `Ctrl` + `,` |
| Keyboard shortcuts | `Ctrl` + `/` |

> [!TIP]
> `Esc` always closes the topmost thing: a menu, a popover, the palette, a dialog, the find bar, then focus mode.

## In the editor

| Action | Shortcut |
| --- | --- |
| Bold / italic | `Ctrl` + `B` / `I` |
| Link | `Ctrl` + `K` |
| Inline code | `Ctrl` + `Shift` + `C` |
| Strikethrough | `Ctrl` + `Shift` + `X` |
| Heading 1 / 2 / 3 | `Ctrl` + `Alt` + `1` / `2` / `3` |
| Quote | `Ctrl` + `Shift` + `.` |
| Bulleted / numbered / task list | `Ctrl` + `Shift` + `8` / `7` / `9` |
| Paste as plain text | `Ctrl` + `Shift` + `V` |

While the editor has focus its own shortcuts win: `Ctrl` + `B` makes text bold instead of hiding the sidebar, and `Ctrl` + `K` inserts a link (the palette is still `Ctrl` + `Shift` + `P`).
