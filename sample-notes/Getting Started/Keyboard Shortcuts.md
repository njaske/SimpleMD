# Keyboard Shortcuts

A short, honest list. Nothing you need to memorize.

## Window

| Action | Shortcut |
| --- | --- |
| Toggle sidebar | `Ctrl / Cmd` + `B` |
| Toggle outline | `Ctrl / Cmd` + `\` |
| Open search | `Ctrl / Cmd` + `F` |
| Save document | `Ctrl / Cmd` + `S` |
| Close tab | `Ctrl / Cmd` + `W` |
| Export to PDF | `Ctrl / Cmd` + `P` |
| Switch theme | `Ctrl / Cmd` + `Shift` + `D` |

## Reading and writing

Use the segmented control at the top right to move between **Read**, **Split**, and **Edit**. Export the current document to PDF from the same toolbar.

> Tip: in Split view, the preview tracks your edits as you type.
